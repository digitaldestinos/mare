# Finance services

Esta camada contém apenas os pontos de extensão do domínio financeiro. Os serviços são stubs intencionalmente vazios nesta sprint: não possuem acesso a banco, Supabase, CRUD ou efeitos colaterais.

As regras de negócio devem ser adicionadas aqui, enquanto os contratos de entrada permanecem em `features/*/schemas` e as entidades em `types/finance.ts`.
